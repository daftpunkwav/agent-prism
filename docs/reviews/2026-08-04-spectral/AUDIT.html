H3TraceView 渲染 key 不稳定

位置 · tests/test_frontend_session_contracts.py + frontend/src/components/TraceView.tsx

测试期望源码含 thought:${step} 类稳定 React key，实际不存在。TraceDiff 与多轮续聊场景下，事件数组索引变化会导致组件不必要地重渲染、闪烁。

修复：key={`thought:${step}:${turn}`}（后端已在 runner.py:122 注入 turn）。
