01安全性

H1.env 包含真实 API Key

位置 · .env:1-13 · 完整 64 字符明文（已 脱敏展示：LLM_API_KEY=7kaS8nK...PZx7I）

事实：.gitignore:10 正确忽略 .env（含 !.env.example 豁免）—— 未提交到 git，但工作区当前存在该文件，未跟踪。

风险：密钥明文落地是安全事件的常见入口。 若在编辑器、终端命令误用（如 cat .env 截图、IDE 同步到云端）会泄露。

修复步骤

  1. 立即撤销该 Key：登录 StepFun 控制台轮换 LLM_API_KEY
  2. 从工作区物理删除：rm .env（有 .env.example 模板）
  3. 未来从 Settings 页面填写（应用已支持「本地保存到 data/provider_config.json」）
  4. 必须保留本地 Key 时，chmod 600 .env（已正确被 .gitignore）
  5. 文档 CLAUDE.md 加一条「严禁将真实 API Key 写入 .env」

与既有审查的差异：既有审查未涉及工作区文件检查，仅关注代码层。密钥管理是流程 + 代码双层问题。

位置 · api/arena.py:122-171

所有 workspace 端点直接接受 URL 路径参数 workspace_name 调 _ws_mgr.get， 无任何会话/所有权/token 校验。注释 arena.py:115-117 已明确「单用户本地部署模型」。

M2_run_sem 全局化导致跨请求串行

位置 · api/arena.py:77

max_concurrent_runs=4 意味着整个后端最多 4 个并发 Arena run。 100 个不同浏览器用户各发 1 个 run → 第 5 个请求会被阻塞，即使前后端都健康。

建议：CLAUDE.md 明确「单用户本地，故意设计」即可，无须代码改动。 长期若需多用户，改为请求级 Semaphore 或 aiolimiter。

L1runner.py finally 中 leaked 仅日志无操作

位置 · arena/runner.py:96-102

检测到 leaked worker 仅 logger.warning，未 cancel 也未等待。 建议补 cancel + wait，与 except 分支对齐。

L2Workspace.rag_store() 内部构建无锁

位置 · arena/workspace.py:84-104

WorkspaceManager 用 RLock 保护，但 Workspace.rag_store 惰性构建无锁。 两 worker 在 SSE 中同时调可能各构建一次向量库（add_documents 重复追加）。 建议加 threading.Lock 或缓存绑定文件内容 hash。

03架构与设计

架构整体清晰，REASONING_MODES 注册表模式已示范。 仍有几处"模块级可变全局状态"是隐性技术债。

D1arena/router.py 全局可变字典是隐性单例

位置 · arena/router.py:55-187

_STATIC_DIMENSION_OPTIONS、DIMENSION_OPTIONS、_BASELINE_OPTION_VALUES、 DEFAULT_BASE、_ENDPOINT_CATALOG 都是模块级可变全局状态。 通过 sync_* 三个函数直接 mutate。

问题：测试隔离靠 fixture；运行时无锁。跨用户并发 PUT /api/settings/provider 时 与正在跑的 Arena run 数据竞争。

建议：改为不可变 dataclass；或 route() 每次显式从 ProviderConfig 重建。 若要保留缓存，必须给 sync_* 加锁。

D2注册表风格不一致

位置 · reasoning_graph.py:357-403 vs router.py

ReasoningModeSpec 注册表模式优秀，但 router.py 仍有 5 个平行字典 （_STATIC_DIMENSION_OPTIONS / _BASELINE_ONLY_OPTIONS / _BASELINE_ONLY_LABELS / _FIELD_LABELS / _FIELD_GROUP）。

建议抽 DimensionSpec dataclass，可消除 ~150 行平行数据。

D3FrameworkAdapter.run 的 if False: yield hack

位置 · adapters/base.py:21-40

这是 mypy + Protocol 的已知兼容性 hack，作者已加注释。 改 AsyncGenerator[ArenaEvent, None] 显式签可避免 hack。
